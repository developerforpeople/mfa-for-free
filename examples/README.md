# Examples

Worked examples showing how to apply what NLR Identity teaches in your own projects.

- [`integration-examples/`](integration-examples/) - adding TOTP-based MFA to an existing
  application, framework by framework.

Everything here is **reference material**, not project code. Examples are not imported by the demo
website or the authenticator app, and they may use maintained third-party libraries where the main
project deliberately writes things out by hand for teaching purposes.
